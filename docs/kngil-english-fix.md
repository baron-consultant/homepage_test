# 영문 Service S/W 메뉴 비활성화

- 운영 `/en/kngil/value.html`에서 HTTP 404를 재현했음.
- 공개 영문 메뉴가 참조하는 `en/kngil` 상세 페이지 6개가 저장소에 없는 것을 확인했음.
- 기존 영문 소개 파일 `en/sv_sw_kngil.html`은 운영 비로그인 브라우저에서 로그인 페이지로 이동하는 것을 확인했음.
- 사용자 요청에 따라 영문 공개 헤더의 Service S/W 메뉴 전체를 HTML 주석 처리했음.
- 로그인용 영문 메뉴는 이미 Service S/W가 주석 처리된 상태임을 확인했음.
- 영문 페이지 신규 생성 작업을 중단하고 이번 작업에서 추가한 임시 페이지와 생성 스크립트를 제거했음.
- 로컬 Playwright PC·모바일 검증에서 Service S/W와 큰길 링크가 숨겨지고 나머지 헤더 링크가 유지되는 것을 확인했음.
