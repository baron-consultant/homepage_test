# 홈페이지 속도 개선 작업 보고

## 1. 작업 범위

- 저장소를 `baron-consultant/homepage_test`로 변경하고 최신 코드를 반영했음
- 리팩토링 없이 이미지 경량화와 로딩 우선순위를 조정했음
- HTML 155개 검사와 개선 전후 성능 측정 48회를 진행했음
- 데스크톱·모바일 너비에서 메뉴·이미지·스크롤 검사 22건을 진행했음

## 2. 주요 속도 개선 결과

- 로컬 환경에서 다운로드 10 Mbps, 지연 40 ms, CPU 4배 감속, 캐시 비활성화 조건으로 측정했음
- **첫 화면 표시 시간(LCP)의 3회 중앙값**으로 비교했음
- 운영 서버의 실사용 환경 측정은 포함하지 않았음

| 페이지 | 개선 전 | 개선 후 | 단축 |
|---|---:|---:|---:|
| EG-BIM 소개 | 13.90초 | 1.63초 | 88% |
| TOVA 소개 | 8.10초 | 1.96초 | 76% |
| GAIA 소개 | 11.35초 | 2.55초 | 78% |

- 측정한 8개 페이지의 LCP가 약 57~88% 개선됐음
- GAIA 주요기능의 전체 로딩은 전후 모두 15초를 초과했음
- HTML·초기 스크립트 준비 시간(DCL)은 0.02~0.45초 증가했음

## 3. 적용 내용

- 메인 영상을 약 118 MB → 8.27 MB로 경량화했음
- 패키지 이미지 383개를 최적화하고 메인 포스터 1개·채용 이미지 4개를 생성했음
- 사진 배경의 크기·품질을 조정하고 도면·UI 캡처에 무손실 압축을 적용했음
- 첫 화면 이미지 우선 로딩과 초기 숨김 이미지 지연 로딩을 적용했음
- 폰트 표시와 공통 HTML 중복 요청을 개선했음
- 브라우저 비교에서 차이가 남은 SVG 2개는 원본 참조를 유지했음
- 이미지·영상의 Git 제외 및 별도 업로드 방식을 유지했음
